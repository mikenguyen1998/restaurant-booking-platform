# Architecture Decision Records

Architectural decisions are documented here, one file per decision
(`0001-<short-title>.md`).

A record captures:

- **Context:** the problem and constraints
- **Decision:** what was chosen
- **Alternatives:** what else was considered
- **Consequences:** trade-offs and follow-up work

No decisions have been recorded yet. Candidate decisions with recommendations are
listed as `T-xx` in [open-questions.md](../open-questions.md#technical-decisions);
each one becomes an ADR once accepted.
